# 有序 · 待办清单

一个尽可能简单的中文 Todo 网页：输入事项、勾选完成、点击 × 删除。支持手机和电脑，无框架、无安装依赖。

## 使用与验收

1. 打开网页，输入一件事，点击“添加”或按回车。
2. 勾选事项前的方框，文字应出现删除线，下方待办数量更新；再次勾选可恢复。
3. 刷新页面，事项和完成状态应保留。
4. 点击右侧 × 删除，删除全部后刷新仍应为空。
5. 用手机访问，确认页面无横向滚动，输入与勾选正常。

新版不再显示负责人、截止日期、搜索或复杂统计。首次使用为空清单。原工作任务版的本地数据会自动转换为待办：保留标题，“已完成”对应勾选，其他状态对应未勾选。原数据完整保留在旧存储键 `youxu.tasks.v1` 中，新清单使用 `youxu.todos.v1`，不修改原记录。

## 打开网页

可以直接打开 `index.html`（本地文件的存储行为因浏览器而异），推荐通过 GitHub Pages 访问。也可在仓库目录运行：

```sh
python3 -m http.server 8000
```

浏览器打开 `http://localhost:8000`，无需 Node.js 或 npm。

## GitHub Pages

将代码推送到 GitHub 后，在仓库 **Settings → Pages** 选择 **Deploy from a branch**，分支 **main**、目录 **/ (root)**，保存并等待部署完成。

网址：https://linkinandy.github.io/my-first-web/

已启用 Pages 的仓库推送更新后会自动重新部署；如仍显示旧页面，可强制刷新。

## 数据限制

数据仅保存在当前站点、当前浏览器的 localStorage，不会上传服务器，不跨设备同步。清理浏览器数据、更换浏览器或地址可能导致数据不可见或丢失，请勿用作重要事项的唯一备份。没有登录、服务器或 SQLite 数据库，多标签页同时修改可能互相覆盖，建议使用单个标签页。保存失败会提示且不改变当前清单；读取损坏数据时会暂停操作，不自动覆盖原数据。

## 文件与测试

- `index.html`：页面。
- `styles.css`：自适应样式。
- `app.js`：待办操作、本地保存、旧数据迁移。
- `tests/test_browser.py`：开发用 Chromium 浏览器回归测试。

环境已安装 Python Playwright 和 `/usr/bin/chromium` 时可运行：

```sh
python3 tests/test_browser.py
```

测试工具不是网页的运行依赖。测试使用隔离浏览器和临时 HTTP 服务，不修改实际用户的数据。
